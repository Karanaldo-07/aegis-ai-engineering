# AEGIS — Autonomous AI Engineering

AEGIS is an AI-native software engineering control plane designed to take a product from requirements through architecture, implementation, testing, security review and deployment — with explicit human approval for privileged actions.

## Phase 1 — UI foundation

This first milestone is intentionally frontend-only. It uses realistic mock data and interaction patterns; AI, backend, GitHub write access, RAG, security scanning, CI/CD and production infrastructure will be connected incrementally in later phases.

### Stack

- Next.js + React + TypeScript
- Lucide icons
- Responsive dark control-plane UI

### Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
